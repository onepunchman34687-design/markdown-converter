## Atmosphere
Technical, clean, and efficient with a warm, approachable feel. The interface should feel precise and reliable while maintaining a friendly, accessible tone.

## Color
- Background: Tan (#d2b48c) - warm, inviting, professional
- Primary Accent: Cedar (#bc6625) - rich, earthy, distinctive
- Surface: Dark charcoal (#161616) for contrast and depth
- Text: Light gray (#f0f0f0) on dark surfaces, #032F30 on light surfaces
- Success: Green (#4caf50)
- Error: Red (#ef5350)

## Typography
- Primary Font: Inter, -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif
- Code Font: 'Monaco', 'Menlo', 'Courier New', monospace
- Hierarchy: Clear distinction between headings, body text, and UI elements
- Weight usage: Bold for primary actions and headings, regular for body, medium for labels

## Spacing
- Base unit: 8px
- Border radius: 12px for softness and modernity
- Padding: Generous touch targets (minimum 44x44px for interactive elements)
- Gap: Consistent spacing between elements (8-24px depending on context)

## Motion
- Page transitions: Slide animations between views (left/right)
- Interactive feedback: Subtle scale and color changes on hover/press
- Loading states: Skeleton placeholders or spinners where appropriate
- Duration: 150-300ms for routine transitions, 300-500ms for page changes
- Easing: cubic-bezier(0.4, 0, 0.2, 1) for standard transitions
